## What you rejected or rewrote

AI suggested adding an “attention needed” flag for courses that are already stale and mostly complete. It proposed using needsAttention: true for when a course has had no activity for over 30 days and is at least 75% complete.

I did not keep this suggestion as I think that using the quick-wins flag is a better criteria to use for validating user's re-engagement. A stale course over 30 days might discourage the user vs a course with just one lesson to complete.
